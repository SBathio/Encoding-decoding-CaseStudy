# Encoding-Decoding Case Study

A Java-based Spring Boot application was developed to demonstrate encoding and decoding mechanisms in a secure and modular structure. Originally created as part of an Infosys case study.

---

## 🚀 Features
- Encode and decode user input using Base64
- Simple and intuitive web-based interface
- Logs and displays operation results
- Modular Java architecture using Spring Boot

---

## 🔧 Tech Stack
- Java 17
- Spring Boot
- Maven
- HTML/CSS (for UI)

---

## 📦 Setup Instructions

### 1. Clone the Repository
```bash
git clone https://github.com/SBathio/Encoding-decoding-CaseStudy.git
cd Encoding-decoding-CaseStudy
```

### 2. Build and Run the Application
```bash
mvn clean install
mvn spring-boot:run
```

Once the application is running, visit:
```
http://localhost:8080
```

## 🧪 Example Usage
1. Launch the web interface.
2. Enter text into the input field.
3. Click **Encode** or **Decode**.
4. View the result and optionally copy it.

**Input:** `Welcome123`  
**Encoded Output:** `V2VsY29tZTEyMw==`  
**Decoded Output:** `Welcome123`
